# 飞书 Playbook

> 从真实任务进入，搭建飞书、AI、自动化与 Agent 工作系统的中文实战手册。

## 读者路线

- 普通飞书用户：从每日简报、会议行动、日程和项目记忆开始。
- 个人开发者：使用官方 CLI 连接日历、任务、文档、妙记和 Base。
- 团队负责人：用 Base、工作流、AI、审批和 OKR 搭建业务流程。
- Agent 开发者：使用 CLI、MCP、OpenAPI、事件订阅和 Skill 工程。

## 15 分钟起步

第一套工作流优先选择高频、输入清楚、结果可检查的任务。每日简报读取当天日历和未完成任务；会议到行动把结论、行动、待确认问题和下一次时间承诺分开处理。

## 飞书模块分工

- 消息与卡片：提醒、确认和短交互。
- 文档：方案、纪要、报告和成稿。
- 知识库：SOP、项目首页和稳定目录。
- 多维表格：对象、状态、关系、视图和工作流。
- 任务：负责人、截止日期和完成状态。
- 日历：真实时间承诺。
- 妙记：会议逐字稿、章节、总结和待办。
- 审批：正式授权动作。
- OKR：目标、关键结果、对齐和进展。
- 飞书 AI / aily：问答、生成、知识连接和智能伙伴。
- 妙搭 Apps：静态工具、全栈应用和云端 AI 生成。

## 工具选择

1. 文档总结与知识问答使用飞书 AI。
2. 表格批量处理使用 Base AI 字段。
3. 状态变化使用 Base 自动化与工作流。
4. 飞书内智能伙伴使用 aily。
5. 个人 Agent 操作飞书使用官方 CLI。
6. MCP 客户端使用官方 OpenAPI MCP。
7. 长期在线服务使用 OpenAPI 与事件订阅。

截至 2026-07-13，`@larksuite/cli` 最新 npm 版本为 `1.0.68`。官方 README 列出 200+ 命令、18 个业务域和 26 个 Agent Skills。

```bash
npx @larksuite/cli@latest install
lark-cli config init --new
lark-cli auth login --recommend
lark-cli auth status
```

## 核心工作流

- 每日工作简报
- 会议到行动
- 日程安排助手
- 个人 CRM
- 项目记忆与带引用问答
- Markdown 发布、同步与备份
- Base AI 批量处理
- aily 业务智能伙伴
- 审批与后续任务
- OKR 周进展
- 妙搭业务应用
- Coding Agent 飞书入口
- 事件驱动机器人
- 行业信号与内容管道
- 数据库与 Base 协同

## 默认工作合同

```text
Read → Plan → Confirm → Write → Verify → Report
```

每次运行读取真实对象与权限，展示计划，在关键动作前确认，执行最小写入，回读结果，并返回链接、用量与待处理事项。

## 最小个人工作系统

- `Projects`：项目、目标、状态、下一步和权威来源。
- `Actions`：行动、负责人、日期、来源和幂等键。
- `Inbox`：消息、会议、文档和信号的待处理入口。
- `Agent Runs`：触发、身份、计划写入、实际写入、错误、用量和结果链接。

## 长期运行

按身份和动作拆分权限；为外发、审批、删除、生产发布和批量操作设置确认；使用稳定主键、分页、增量游标、结构化错误、写后回读、待处理视图、配额告警和可恢复备份。

## 30 天路线

- 第 1 周：固定信息入口，人工跑通第一套工作流。
- 第 2 周：接入 Base 自动化、AI 字段、幂等与运行记录。
- 第 3 周：连接项目知识、官方 CLI 和一个窄场景 Skill。
- 第 4 周：接入事件、权限、告警、备份与月度复盘。
